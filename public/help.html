A little space to get started.

Your first three steps

  1. Start an empty workspace or explore sample notes. Use the blue + button to capture a note.
  2. Select a note to edit its title, details, checklist, color, priority, project, or due date. Move it through To Do, In Progress, and Done using its stage controls.
  3. Open Settings → Data & backups to download a complete JSON backup. Your workspace is stored only in this browser on this device.

Quick capture

Try Review draft tomorrow p1 #work. Quick capture recognizes today, tomorrow, this evening, “in 3 days”, priorities p1–p4, and #tags. It does not parse clock times or weekday names. Review the preview before adding.

Find your way

Use Ctrl+K (⌘K on Mac) or the search button to find notes, open a project, or switch views. Press N outside a text field to capture a note. Press Escape to close dialogs.

The board shows all notes by status. Workflow sections organize notes by where you place them; Today also includes active notes due today or overdue. Upcoming shows unfinished scheduled work. Use projects to group related notes.

Canvas and focus

Canvas Wall is a separate space for visual ideas. Add notes or upload photos with the toolbar. On a computer, drag items, double-click to edit text, and use Ctrl+Z / Ctrl+Shift+Z to undo or redo while the canvas is open. Canvas history resets when you leave the view. Touch support is limited; use the board or workflow lists on small screens.

Focus Room offers a 25-minute focus timer and a 5-minute break. Complete a focus session to add its duration to the selected note. Session counts apply to your current visit to Focus Room. Leaving the view stops that timer. Task stopwatches run while the app is open and pause after reloading.

Install and offline use

On supported browsers, use the browser menu's Install app or Add to Home Screen option. Visit online once and allow the offline cache to finish before relying on offline access. Installed browser apps use the same local workspace as that browser profile. Windows desktop workspaces are separate; transfer using JSON backups.

Share useful feedback

Send feedback through the same place where you received the launch link. Include what you tried, what you expected, what happened, your device/browser, and whether the issue repeats. A direct support address has not been configured in this beta.
